# 账单导入本地验收记录

## 范围与状态

本次交付为 v0.3.0 的人工账单导入闭环：版本化迁移、支付宝 CSV、微信 CSV/XLSX、可恢复预览、来源去重、账户映射、人工分类与修正、原子提交及 Nuxt UI 工作台。AI 分类（#76）、共享模型（#86）与退款自动关联未实现，父 Issue #81 不应按完整 AI 范围关闭。本记录不代表版本已发布或远端 CI 已通过。

## 真实账单核对

在用户授权的本地目录读取原始文件，所有写入均使用隔离临时数据库。原始账单和验收数据库不提交到 Git；仓库 fixture 已替换身份、支付账户、商品、单号、金额与时间。补充扫描真实样本中的 1,621 个平台及商户单号，待交付文件零命中；该扫描只验证单号，不代替完整脱敏检查。

| 来源 | 原始数据行 | 普通候选 | 退款排除 | 其他跳过 | 不支持 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 支付宝 CSV（GB18030） | 771 | 599 | 35 | 134 | 3 |
| 微信 XLSX | 169 | 164 | 4 | 1 | 0 |

真实样本测试使用独立 CSV/OpenPyXL 读取结果比对解析行数、整数分与方向金额，再通过 HTTP 上传、人工分类、提交、读取交易与重传去重完成验收。支付宝逐行支出减退款与平台摘要相符；首版退款未入账，因此不能宣称导入后的净支出等于平台净额。
