## 处理原则

- 删除开发验收专用的消息反馈预览及其测试，不把 Toast、组件实现或主题 token 说明暴露给用户。
- 删除实现细节和技术术语，例如服务端筛选、真实父分类关系、时间桶、Tag 和分页实现；改为用户可直接理解的中文。
- 保留账务语义和可执行帮助，例如退款额度、余额调整、标签可能重复计入、日期范围和分类用途提示。
- 不改变路由、请求参数、账务规则、数据展示逻辑或键盘/无障碍交互。
