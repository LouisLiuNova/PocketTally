# PocketTally 文档

PocketTally 是面向单个账本所有者的个人记账应用。根据你要完成的任务，选择对应的文档入口。

- [用户文档](user/index.md)：创建账户、记账、查询统计、纠错和常见问题。
- [开发者文档](developer/index.md)：部署与备份、认证恢复、参与开发、测试和技术契约。

> **文档版本说明**
> 这套文档为 **v0.2.0 发布预览**。当前公开发行版仍为 v0.1.0，使用旧镜像时请阅读 [v0.1.0 发行说明](releases/v0.1.0.md)。发布时将核对文档与实际镜像及部署方式一致。

文档由仓库内容与契约文件生成；页面版本信息对应构建时的代码提交。
