# PocketTally v0.1.0 发行说明

v0.1.0 是 PocketTally 的首个发布版本，也是首个已发布的 SQLite 数据库基线。本说明可
直接作为 GitHub Release 的正文草稿；只有 `v0.1.0` 标签流水线通过并确认四个公开镜像
清单均可匿名拉取后，才可以宣布正式镜像发布完成。

## 支持边界

- 面向个人、单用户、本地 SQLite 账本。
- 仅支持本机或可信内网部署；没有登录鉴权，不支持公网端口转发或公网 VPS。
- 正式容器支持 `linux/amd64` 与 `linux/arm64`，对应 Linux x86_64 和 macOS Apple
  Silicon 的 Docker 环境。
- 桌面浏览器验收只覆盖 Chromium 的 1280、1440、1920 三档宽度；Firefox、WebKit 和
  移动端不是 v0.1.0 的兼容性承诺。

## 主要能力

- 账户、分类与标签管理，收入、支出、转账、调账、交易编辑和幂等作废。
- 支出退款、退款限额、余额原子更新和可重建的账户余额投影。
- 分页交易、退款摘要、六类服务端统计和消费下钻。
- 统计使用 `Asia/Shanghai` 日期边界，支持退款双重归属、分类树递归归集和 Tag 非互斥
  维度；十万笔账本正确性与 p95 性能门禁已建立。
- SQLite 在线一致备份、完整性校验、停机恢复和恢复前快照。

## 正式部署

正式部署固定使用 `0.1.0`，不要使用可变的 `latest`：

```bash
cp .env.example .env
mkdir -p data backups
docker compose pull frontend backend
docker compose up -d --no-build
docker compose ps
curl --fail http://127.0.0.1:54425/api/v1/health
```

`.env` 中必须保留：

```dotenv
POCKET_TALLY_IMAGE_TAG=0.1.0
```

镜像地址：

- `ghcr.io/louisliunova/pockettally-frontend:0.1.0`
- `ghcr.io/louisliunova/pockettally-backend:0.1.0`
- `iridium191/pocket-tally-frontend:0.1.0`
- `iridium191/pocket-tally-backend:0.1.0`

完整的目录权限、日志、升级和恢复步骤见
[《Docker Compose 内网部署》](https://louisliunova.github.io/PocketTally/deployment/)。

## 备份要求

首次保存真实数据前必须创建并校验备份：

```bash
docker compose run --rm backup create
docker compose run --rm backup verify <上一步输出的备份文件名>
```

校验通过后，把备份复制到另一块磁盘或另一台设备。日常使用和每次升级前都应再次创建、
校验并复制备份；只保存在同一宿主磁盘上的副本不能防止磁盘故障。

## 已知限制

- v0.1.0 没有身份验证或会话管理。单用户公网安全边界由 Issue #22 在 v0.2 处理。
- 当前没有版本化数据库迁移。任何后续 Schema 变更前必须建立迁移，或明确版本兼容、
  升级前备份与恢复策略；不能假定只回退镜像即可回退数据库。
- 不支持多用户所有权和资源隔离、数据导入、拆分交易、冲正或完整更正链。
- 不支持手工 SQL 或第三方程序直接写入数据库。
- v0.1.0 是首个发行版本，没有更早的发行镜像可供回退；首次部署异常时应停止服务并
  恢复开始录入前的已校验基线备份。
