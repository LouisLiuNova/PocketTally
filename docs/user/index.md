# 用户文档

不需要了解服务器或数据库，也可以按这里的步骤使用 PocketTally。部署、备份和密码恢复由账本管理员处理；如果你自己管理服务，请转到[开发者文档](../developer/index.md)。

## 从这里开始

1. [开始使用](getting-started.md)：登录、创建账户、录入现有余额。
2. [日常记账](transactions.md)：收入、支出、转账、余额调整、分类和标签。
3. [查询与统计](insights.md)：找到交易，理解各类统计。
4. [纠错与退款](corrections.md)：修改、作废和处理支出退款。
5. [常见问题](faq.md)：常见使用边界与下一步。

这套页面描述 v0.2.0 发布预览。当前公开 v0.1.0 镜像的使用边界以[历史发行说明](../releases/v0.1.0.md)为准。
