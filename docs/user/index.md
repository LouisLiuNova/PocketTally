# 用户文档

不需要了解服务器或数据库，也可以按这里的步骤使用 PocketTally。部署、备份和密码恢复由账本管理员处理；如果你自己管理服务，请转到[开发者文档](../developer/index.md)。

## 从这里开始

- [开始使用](getting-started.md)：登录、创建账户，并把已有余额准确录入账本。
- [日常记账](transactions.md)：记录收入、支出、转账与余额调整，管理分类和标签。
- [查询与统计](insights.md)：搜索交易记录，阅读收支趋势和分类汇总。
- [纠错与退款](corrections.md)：修改或作废交易，并从原支出发起退款。
- [常见问题](faq.md)：查看账户余额、作废记录、密码恢复等常见问题。

这套页面适用于 v0.2.0。v0.1.0 镜像的使用边界以[历史发行说明](../releases/v0.1.0.md)为准。
