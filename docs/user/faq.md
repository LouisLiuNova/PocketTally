# 常见问题

## 为什么新账户余额是零？

新账户不会推测你已有的余额。请用“调账”录入与现实余额之间的差额。

## 找不到已作废的交易？

交易列表默认隐藏已作废记录。将状态筛选切换为“全部状态”或“仅作废”。

## 退款可以直接记为收入吗？

请从原支出详情发起退款，以免收支统计重复计算。

## 忘记密码或需要恢复账本？

请联系账本管理员。自行管理服务时，请阅读[认证与会话](../developer/authentication.md)和[部署与备份](../developer/deployment.md)。

## 可以让多人共用一个账本吗？

当前版本面向单个所有者，不提供独立的多用户账户或团队权限。
