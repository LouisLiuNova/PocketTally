# 导入个人账单

当前开发分支支持支付宝 CSV、微信 CSV/XLSX 的人工分类导入。使用发布镜像前，确认版本包含此功能。

1. 从平台导出个人交易明细。直接选择 CSV 或 XLSX；ZIP 压缩包需先解压。文件最多 10 MiB、10,000 条交易记录。
2. 在“账单导入”选择文件并解析。解析后会保存草稿，刷新页面或从导入历史选择批次可以继续处理。
3. 按来源支付方式选择已有账户，并分别为收入、支出设置分类。可选择在成功提交后记住账户映射；后续账单将使用该映射建议。
4. 筛选待补账户或待补分类记录，逐行修正账户、分类、金额、时间及说明。来源详情保留平台原记录。对不准备入账的候选取消“纳入”。
5. 核对纳入数量和收支金额，打开“确认导入”，再提交整批。提交失败会保留草稿；没有部分入账。

首次导入前，先建立实际账户，并通过余额调整记录导入期间开始前的余额。借记账户最终余额不足会阻止提交；应核对账户、来源金额和期初余额，不能为通过导入随意增加余额。

平台单号相同且此前成功导入的记录会标为重复，即使原交易已作废也不会再次入账。相似手工交易只提供提示，请自行核对。预览期间若其他批次占用了来源单号，需要重新读取并明确排除重复记录。

首版识别并跳过退款，不能把退款当普通收入；也排除零金额、理财、借还、账户存取等不属于普通收支的记录。可在状态筛选中核对原因。平台摘要可能已经扣除退款，而本次导入没有自动入账退款，因此两者净支出可能不同；需要从原支出单独记录退款。

未提交草稿可以删除；已提交批次保留来源审计信息。导入后的交易按日常交易流程修正或作废。
