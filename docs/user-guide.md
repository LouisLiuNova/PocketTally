# 用户指南

PocketTally 是一款轻量、私有的个人记账应用。数据保存在你自己的 SQLite 账本中，适合在本机或可信内网使用。

> [!WARNING]
> 当前版本没有登录功能。请勿将服务暴露到公网，也不要让其他程序直接修改数据库。

## 首次使用

1. 按[部署与备份](deployment.md)启动服务，并确认健康检查正常。
2. 创建第一个账户。
3. 使用调账录入当前余额，让账本从真实余额开始。
4. 根据需要调整预置的收入和支出分类。
5. 开始记录收入、支出、转账和退款。

## 日常记账

- 使用账户、分类和标签组织交易。
- 用搜索和筛选快速定位交易。
- 在统计页面查看收支趋势、分类构成和日历汇总。
- 需要修正余额时使用调账，并保留清晰的备注。

金额、时间、退款和报表的详细口径见[业务规则](business-rules.md)。

## 备份与升级

在保存真实数据前先创建并校验备份。升级镜像前停止写入，完成备份后再按[部署指南](deployment.md)的升级和恢复步骤操作。

## 当前限制

PocketTally 当前面向单用户、本机或可信内网部署。登录、多用户隔离和公网发布不属于当前版本的使用边界；版本能力与已知限制见[v0.1.0 发行说明](releases/v0.1.0.md)。
